# Trilha de introdução à pesquisa · Isso é normal?

Página com os materiais da trilha do dotLAB para as estudantes do projeto Isso é normal?.

## Como publicar um material aprovado

1. Envie o PDF para a pasta `pdfs/`.
2. Em `index.html`, procure a linha do material na lista `MATS` e acrescente `pdf`, `pag` e `ver`. Exemplo:

```js
{n:"2", t:"Documento de estudo: o problema e a justificativa", d:"...", tipo:"p", pdf:"pdfs/02-documento-de-estudo-v1.0.pdf", pag:9, ver:"Versão 1.0 · outubro de 2026"},
```

3. Salve (commit). O GitHub Pages atualiza a página em um ou dois minutos.
