Bootstrap ao vivo

Se o jogo fosse aplicado de novo, quanto a média poderia mudar?

O bootstrap sorteia, com reposição, novas amostras do mesmo tamanho a partir das partidas que temos e calcula a média de cada uma. Use os botões para fazer os sorteios você mesma.

Leia assim

Cada sorteio é uma base “parecida” com a nossa, e cada média cai num lugar um pouco diferente. Com milhares de sorteios, as médias formam um morro. Descartando os 2,5% de cada ponta, sobra o intervalo de confiança de 95%.

No notebook, com a semente 42, o resultado é . Aqui os sorteios não usam semente, então os limites variam um pouco a cada vez, mas ficam sempre perto desses valores.

Como fizemos
rng = np.random.default_rng(42)          # gerador de sorteios; 42 é a semente
medias = [rng.choice(p, size=len(p), replace=True).mean() for _ in range(10_000)]
inf, sup = np.percentile(medias, [2.5, 97.5])
print(f"média {p.mean():.2f}, IC 95% [{inf:.2f}; {sup:.2f}]")

Cada ponto é uma partida. O traço escuro marca a mediana de cada instituição (upe 10, fms 9, cdia 10). A instituição “outra” fica de fora por ter poucas partidas.

Clique em “Sortear um par” para ver de onde vem o r.

Leia assim

Imagine sortear uma partida de cada instituição e ver qual pontuou mais. O r é a chance de a primeira ganhar menos a chance de ela perder. A barra acima mostra essas chances contando todos os pares possíveis. Perto de 0, nenhuma das duas tende a pontuar mais.

O valor-p diz se uma diferença desse tamanho seria comum caso as instituições fossem iguais. Ele depende do número de partidas: com poucos dados, até um efeito real pode ficar acima de 0,05.

Como fizemos
grupos = {i: res.loc[res["instituicao"] == i, "pontuacao"] for i in ["upe", "fms", "cdia"]}
print(stats.kruskal(*grupos.values()))

u = stats.mannwhitneyu(grupos["upe"], grupos["fms"])
n1, n2 = len(grupos["upe"]), len(grupos["fms"])
r = 2 * u.statistic / (n1 * n2) - 1      # tamanho de efeito
print(round(u.pvalue, 3), round(r, 2))

Nesta página, o valor-p é calculado como no SciPy: aproximação normal, com correção para empates e de continuidade.

Cada carta, por dentro

Que cartas são mais difíceis? Cada carta separa quem reconhece os sinais de quem não reconhece?

Barra: proporção de acerto (dificuldade). Número à direita: discriminação. alerta gabarito “Vale investigar”; comum gabarito “É comum”.

Leia assim

A dificuldade é a proporção de acerto: quanto menor, mais difícil a carta. As cartas do intestino e da urina são as mais difíceis, com 43% de acerto cada.

A discriminação é a correlação entre acertar a carta e a pontuação nas outras 12 (ponto-bisserial corrigida). Valores acima de 0,30 indicam que a carta separa bem quem reconhece os sinais; abaixo de 0,20, ela quase não separa e é candidata a revisão. As cartas comuns têm a discriminação mais baixa.

O KR-20 mede se as 13 cartas medem um mesmo construto: . Valores a partir de 0,70 costumam ser considerados aceitáveis.

Como fizemos
dificuldade = acertos.mean()                    # proporção de acerto de cada carta
total = acertos.sum(axis=1)
discriminacao = {c: np.corrcoef(acertos[c], total - acertos[c])[0, 1] for c in cartas}

k = len(cartas)
pq = (acertos.mean() * (1 - acertos.mean())).sum()
kr20 = k / (k - 1) * (1 - pq / total.var(ddof=0))

Tipos de erro · detecção de sinal

Errar por não distinguir ou por normalizar?

As jogadoras erram porque não distinguem um sinal de alerta de algo comum, ou porque tendem a achar tudo normal?

Para cada jogadora, calculamos a sensibilidade (a proporção das 9 cartas de alerta marcadas como “Vale investigar”) e a especificidade (a proporção das 4 cartas comuns marcadas como “É comum”). Com elas, a teoria de detecção de sinal calcula dois números:

  • d′: a capacidade de distinguir um sinal de alerta de algo comum. Quanto maior, melhor.
  • critério c: o viés de resposta. Positivo, a pessoa tende a normalizar (“é tudo normal”); negativo, tende a alarmar (“tudo é grave”).

Cada ponto é uma jogadora. Clique num ponto para ver as 13 respostas dela.

Leia assim

Em média, a sensibilidade é e a especificidade, : as jogadoras deixam passar mais sinais de alerta do que dão alarmes falsos. O critério c médio é , positivo: o erro mais frequente é normalizar.

São problemas diferentes, com ações educativas diferentes. Quem não distingue (d′ baixo) precisa aprender o que diferencia cada sinal. Quem normaliza (c alto) já distingue, mas precisa aprender que a dor intensa não é normal.

Como fizemos
alerta = [c for c in cartas if gabarito[c] == "r"]
comuns = [c for c in cartas if gabarito[c] == "l"]
sens = (res[alerta] == "r").mean(axis=1)      # sinais de alerta reconhecidos
fa = (res[comuns] == "r").mean(axis=1)        # alarmes falsos nas situações comuns

ajusta = lambda x, n: x.clip(1 / (2 * n), 1 - 1 / (2 * n))   # evita 0 e 1
z = stats.norm.ppf
d = z(ajusta(sens, 9)) - z(ajusta(fa, 4))
c = -(z(ajusta(sens, 9)) + z(ajusta(fa, 4))) / 2

O ajuste evita proporções de 0 ou 1, para as quais o valor z seria infinito.
